# My-M5-CardputerADV-OS

I'm learning how to make my first OS for the M5Stack Cardputer ADV! It took me a while to figure out how everything works, but I've finally managed to get a basic menu working.

I'm still learning how `void loop()` and other parts of Arduino work, but I'm getting better at it. Feel free to use my code for your own projects!

## What's Included

There are currently three different projects in this repository:

### 1. Menu System

A basic menu with four options:
- Notes
- Games
- Clock
- Settings

You can move up and down using the keyboard and press Enter to select an option. The menu is still pretty basic, and the apps don't actually work yet. This was my first project using the Cardputer ADV, so I wanted to start simple!

### 2. Random Color Picker

Press buttons on the Cardputer keyboard to generate random colors. The button you press doesn't affect the color; it's completely random!

### 3. Reaction Time

A little reaction-time game where you try to get the fastest time. This one was fun to make because I got to work with timers!

## Menu Controls

| Key | Action |
|---|---|
| `;` | Up |
| `.` | Down |
| `Enter` | Select |

## How to Use

1. Download the code from this repository.
2. Open the project you want in Arduino IDE.
3. Make sure the M5Stack board package and M5Cardputer library are installed.
4. Select the M5Cardputer board.
5. Connect your Cardputer ADV.
6. Compile and upload the code!
