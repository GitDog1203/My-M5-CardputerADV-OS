# My-M5-CardputerADV-OS
Im learning to make my 1st OS for the cardputer. It took me a while to understand much of it but I got the base of the Menu! Still learning features with void Loop() and other stuff
like that but Im doing better on void setup().
Feel free to use it for other projects!

There are 3 diffent files, one is a random color picker, it uses random pressing of any button on the keyboard to generate a completly random color. The second is a base menu that dosnt have anything special right now. Last is a reaction time which you click and try to get the quickest reaction.
 To use download the code and flash it in arduino IDE
